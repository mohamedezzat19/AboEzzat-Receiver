# AboEzzat Receiver

مستقبل وسائط لأجهزة Android TV وأجهزة Android المتصلة بالشبكة المحلية، يعمل مع تطبيق **AboEzzat Share**.

## الوظائف الحالية
- استقبال روابط الفيديو والصوت والصور وتشغيلها باستخدام AndroidX Media3 / ExoPlayer.
- تشغيل بث HLS وDASH بحسب توافق المصدر والجهاز.
- عرض عنوان IP الحالي وتحديثه عند تغيّر الشبكة.
- اكتشاف الجهاز على الشبكة المحلية عبر multicast، مع دعم الاتصال اليدوي من تطبيق Share.
- استقبال أوامر التحكم بالتشغيل والإيقاف المؤقت والتقديم/الترجيع ومستوى الصوت وكتمه.
- واجهة ترحيب وحالة اتصال، مع إبقاء الشاشة مستيقظة أثناء الاستخدام.

## الاتصال
1. افتح Receiver وانتظر ظهور عنوان IP والمنفذ **8081**.
2. افتح تطبيق Share على الهاتف، واجعل الجهازين على الشبكة المحلية نفسها.
3. اكتشف Receiver تلقائيًا أو أدخل عنوان IP في إعدادات Share.
4. عند بث ملف محلي من الهاتف، يبقى Share مفتوحًا ليقدّم الملف مؤقتًا على المنفذ **8082**.

التطبيق مخصص لشبكة موثوقة؛ لا تعرض منفذ التحكم على الإنترنت. قد تفشل بعض الروابط بسبب DRM أو قيود المصدر أو عدم دعم الترميز في الجهاز.

## عقد التشغيل والترويسات والتحكم السحابي

راجع [`docs/playback-request-contract.md`](docs/playback-request-contract.md) لعقد طلب التشغيل المقترح، وسياسة الترويسات الآمنة، واختبارات Media3 المطلوبة. هذا المستند يحدد متطلبات التنفيذ ولا يعني أن تمرير الترويسات أو Firebase أو التحكم السحابي قد تم تفعيله بالفعل.

## البناء
يتطلب Java 17 وAndroid SDK (API 34). من جذر المستودع:

```bash
gradle assembleDebug
```

ملف APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

يمكن تشغيل سير عمل **Build AboEzzat Receiver APK** من تبويب Actions وتنزيل artifact الناتج عن آخر تشغيل ناجح.
